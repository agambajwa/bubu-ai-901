⚡ High-Yield Trap Pairs (Microsoft Loves Testing These)

Fairness vs. Inclusiveness

Fairness: AI treats all similar groups equally without demographic bias (gender, race, age, loans).

Inclusiveness: AI empowers all human abilities (accessibility, screen readers, speech impediments).

Transparency vs. Accountability

Transparency: Humans can understand how and why the model reached a decision.

Accountability: Humans/designers are legally and ethically responsible for outcomes.

Azure AI Vision vs. Custom Vision

AI Vision: Pre-trained model out of the box for 10,000+ generic items, OCR, captions.

Custom Vision: You bring your own images to label domain-specific classes (e.g., your company's product parts).

AI Assistant vs. AI Agent (AI-901 Modern Update)

Assistant: Reactive, turn-by-turn prompt response to boost human user productivity.

Agent: Autonomous, proactive, triggers off events, does multi-step planning towards a user goal.

Multi-modal vs. Multi-model

Multi-modal: A single model handling 2+ formats (e.g., GPT-4o takes text + image in, generates text + audio).

Multi-model: An application pipeline linking multiple separate models (Speech-to-Text → LLM → Text-to-Speech).

Deterministic vs. Generative Models

Deterministic (Language Service): Same input always yields identical structured output (cheaper, consistent).

Generative (OpenAI / LLMs): Probabilistic, creative natural text responses (can vary per run).
